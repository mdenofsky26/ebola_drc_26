# Closing the Gaps: Ebola DRC Data Analysis

Exploratory analysis of DRC Ebola case data to identify response gaps and guide intervention strategies.

## Disclaimer

This is an independent, personal project undertaken to explore Ebola case data and strengthen my own analytical skills, with the broader goal of preparing to support a CDC Emergency Operations Center (EOC) in the near future. This analysis is not affiliated with, endorsed by, or representative of the CDC, WHO, or any official public health agency. Findings should not be used for operational decision-making.
